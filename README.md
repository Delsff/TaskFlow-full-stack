📌 About

A modern, full-stack Task Management application designed to help users organize daily workflows, track progress, and boost productivity. The platform features secure user authentication, real-time notification alerts, and a clean, responsive interface.

📄 Pages / Features

Home / Dashboard — main interface for managing tasks, filtering activities, and viewing real-time updates

Login / Sign Up — secure authentication interface supporting user registration and session management

Notifications — interactive popover menu with live updates and one-click clear options

Tasks Catalog — intuitive task management list supporting status updates, filtering, and deletion

Profile Settings — user profile overview showing current account details and avatar initials

✨ Key Features

🔐 Secure Authentication — user login & registration powered by JWT and hashed passwords

🔔 Interactive Notifications — real-time floating notification panel with unread counters and quick clearing

📱 Fully Responsive — polished UI built to adapt smoothly to mobile, tablet, and desktop screens

⚡ Fast & Reactive — smooth client-side state management for instantaneous feedback

🛠️ Tech Stack

Client (Frontend)
• React — component-based user interface
• Tailwind CSS — utility-first modern styling
• Lucide React — lightweight icon system
• Axios — API client for HTTP requests

Server (Backend)
• Node.js & Express — RESTful API architecture
• MongoDB & Mongoose — NoSQL database for flexible data modeling
• JWT (JSON Web Tokens) — secure user authentication
